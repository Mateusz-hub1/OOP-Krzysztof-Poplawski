# Programowanie obiektowe – C# / Python

Zadania z Programowania obiektowego u Krzysztofa Popławskiego, nadrabiane jako różnice programowe z 1. semestru.

- **Autor:** Mateusz Połącik
- **Kierunek / semestr:** Informatyka, semestr 3
- **Uczelnia:** Uniwersytet WSB Merito

## Zadania

Każde zadanie jest na osobnym branchu:

- `01-podstawy-csharp-python` – przypomnienie podstaw: kalkulator, konwerter temperatur i średnia ocen, w Pythonie i w C#.
- `02-koncepcje-oop` – klasy i obiekty na przykładzie prostego systemu bankowego (konta, wpłaty, wypłaty, przelewy, historia), w Pythonie i w C#.
- `03-praktyczne-oop` – GymLog, czyli konsolowy dziennik treningowy w Pythonie, w którym są wszystkie cztery zasady OOP i relacje między klasami.
- `04-dobre-praktyki` – w przygotowaniu.

## Jak uruchomić

Python: wystarczy Python 3, bez dodatkowych bibliotek.

C#: potrzebny jest .NET SDK, a program odpala się poleceniem `dotnet run` w folderze z plikiem `.csproj`.

Dokładne instrukcje są w README na branchu każdego zadania.
